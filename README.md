# IT Homelab – System Administration & Cloud Engineering

## About This Project

This repository documents my hands-on learning journey in Windows Server administration, networking, Microsoft Azure, cloud security, and DevOps.

My goal is to develop practical skills in system administration, cloud infrastructure, automation, and security.

## Technologies

- Windows Server 2022/2025
- Active Directory Domain Services (AD DS)
- DNS, DHCP, Group Policy
- PowerShell
- Hyper-V
- Microsoft Entra ID
- Microsoft Azure
- Azure Virtual Networks and Network Security Groups

## Completed Labs

### 1. Windows Server & Active Directory

- Configured a domain controller and Active Directory
- Created and managed users, groups, and organizational units
- Configured DNS and Group Policies
- Set up file shares and NTFS permissions
- Troubleshot network connectivity and name resolution

### 2. Microsoft Entra ID & Azure RBAC

- Created cloud users and security groups
- Configured Azure role-based access control (RBAC)
- Assigned the Reader role to a security group
- Tested access permissions using a separate user account
- Examined Entra ID sign-in logs

### 3. Azure Networking

- Created an Azure resource group
- Configured a virtual network with address space 10.10.0.0/16
- Created a server subnet using 10.10.1.0/24
- Created and associated a Network Security Group (NSG)
